    정확한 클릭 꺼짐

    Flow의 → 생성 버튼이 자동으로 눌리지 않을 때 켜세요. 켜면 Chrome이 권한을 물어봅니다. 허락하면 작업하는 동안 Flow 탭에만 실제 마우스 클릭을 보내고, 작업이 끝나면 바로 멈춥니다.

    작업 중에는 Chrome 위쪽에 "Gemini Auto Image이(가) 이 브라우저 디버깅을 시작함"이라는 안내줄이 뜹니다. 정상입니다. 그 줄의 취소를 누르면 그 작업에서는 정확한 클릭이 꺼집니다.

    문제 해결

    잘 안 될 때 Flow 프로젝트 화면을 연 상태에서 누르세요. 버튼과 입력창 위치 정보만 복사되고, 프롬프트 내용이나 계정 정보는 담기지 않습니다. 복사한 내용을 Claude에게 붙여넣어 주세요.

    사용 방법

    1. Google Flow 프로젝트 화면이나 Gemini 대화 화면을 엽니다.
    2. 프롬프트 여러 개는 맨 위 "한꺼번에 넣기"에 붙여넣고, 따로 할 것은 아래 상자 8개에 끌어다 놓습니다.
    3. 비율과 참조 이미지를 고르고 시작을 누릅니다.
    4. 결과는 라이브러리 탭에 모이고 다운로드 폴더에 저장됩니다.
    5. 상자 오른쪽의 ▶ 실행을 누르면 그 상자 하나만 바로 만듭니다. 아래 시작 버튼은 한꺼번에 넣기 목록을 실행합니다.
    6. 생성 버튼이 자동으로 눌리지 않으면 Settings 탭에서 "정확한 클릭"을 켜세요. 꺼져 있으면 Flow의 → 버튼에 노란 테두리가 생기고, 직접 한 번 누르면 이어서 진행합니다.
    7. 상자마다 이미지·동영상과 16:9·9:16을 고르면 Flow 설정을 자동으로 바꾼 뒤 생성합니다. 모델은 맨 위에서 한 번 정하면 그대로 유지됩니다.
