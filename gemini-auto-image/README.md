# Gemini Auto Image

Google Flow와 Gemini에서 여러 프롬프트를 순서대로 자동 입력해 이미지와 동영상을 만드는 Chrome 확장 프로그램입니다.

## 설치

1. 이 `gemini-auto-image` 폴더를 내려받습니다.
2. Chrome 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.
5. 툴바의 확장 프로그램 아이콘을 누르면 오른쪽에 패널이 열립니다.

## 사용

1. Google Flow(flow.google.com) 프로젝트 화면이나 Gemini 대화 화면을 엽니다.
2. 맨 위 **사용 모델**에서 이미지 모델, 동영상 모델, 개수를 정합니다. 바꾸기 전까지 그대로 유지됩니다.
3. 프롬프트가 많으면 맨 위 **한꺼번에 넣기**에 붙여넣습니다. 1, 2, 3 번호나 빈 줄로 나뉜 것을 하나씩 나눕니다.
   끝난 항목은 기억해 두었다가, 다시 시작하면 남은 것부터 이어서 합니다.
   따로 할 프롬프트는 아래 상자 8개에 글이나 .txt 파일을 끌어다 놓습니다. 여러 줄이어도 상자 하나가 프롬프트 하나입니다.
4. 상자마다 이미지·동영상과 16:9·9:16을 고릅니다. 시작하면 Flow 설정을 자동으로 바꾼 뒤 생성합니다.
5. 상자 오른쪽의 **▶ 실행**을 누르면 그 상자 하나만 바로 만듭니다.
   아래 **시작** 버튼은 한꺼번에 넣기 목록을 실행하고, 목록이 비어 있으면 상자 전체를 실행합니다.
6. 실패하면 설정한 횟수만큼 자동으로 다시 시도합니다. Flow에서 30초 동안 아무 반응이 없으면 바로 실패로 판단합니다.
7. 결과는 Library 탭에 모이고, 설정에 따라 다운로드 폴더에 자동 저장됩니다.

## 계정 메모

**계정** 탭에 아이디와 비밀번호를 적어 두고 복사 버튼으로 Google 로그인 화면에 붙여넣을 수 있습니다.
자동 로그인은 하지 않습니다. 정보는 이 PC의 Chrome에만 저장되며 다른 곳으로 보내지 않습니다.

- 처음 열 때 정하는 **잠금 비밀번호**로 모든 계정 정보를 AES-GCM 방식으로 암호화해 저장합니다.
- 잠금 비밀번호 없이는 Chrome 저장소를 직접 열어 봐도 읽을 수 없습니다.
- 패널을 닫거나 5분 동안 쓰지 않으면 자동으로 잠깁니다.
- 잠금 비밀번호를 잊으면 되찾을 수 없고, 저장된 계정을 모두 지우고 새로 설정해야 합니다.

## 정확한 클릭

Flow의 → 생성 버튼은 프로그램이 보낸 클릭을 무시할 수 있습니다. 이때 Settings 탭에서 **정확한 클릭**을 켜세요.
Chrome이 권한을 물어보고, 허락하면 작업하는 동안 Flow 탭에만 실제 마우스 클릭을 보냅니다. 작업이 끝나면 바로 멈춥니다.
작업 중에는 Chrome 위쪽에 디버깅 안내줄이 뜹니다. 언제든 Settings에서 끌 수 있습니다.

## 문제 해결

생성 버튼이 자동으로 눌리지 않으면 Flow의 → 버튼에 노란 테두리가 생기고 패널에 안내가 나옵니다.
그 버튼을 한 번 직접 누르면 작업이 이어지고, 누른 버튼을 기억해 다음부터 그 버튼을 자동으로 누릅니다.

잘 안 되면 Flow 프로젝트 화면을 연 상태에서 Settings 탭의 **Flow 화면 정보 복사**를 누르고, 복사된 내용을 Claude에게 붙여넣어 주세요.
버튼과 입력창 위치 정보만 담기며 프롬프트 내용이나 계정 정보는 담기지 않습니다.

## 참고

- 사이트 화면 구조가 바뀌면 입력창이나 생성 버튼을 찾지 못할 수 있습니다. 상태 줄에 이유가 표시됩니다.
- 생성 버튼이 비활성화되면 사용 한도에 걸린 것으로 보고 작업을 멈춥니다.
