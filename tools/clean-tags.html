HTML 중복 블록 삭제 도구

파일을 올리면 지정한 문구가 들어 있는 블록을 찾아서 지우고, 정리된 파일을 저장해 줍니다. 원본 파일은 변경되지 않습니다.

1. HTML 파일 선택

여기로 HTML 파일을 끌어다 놓거나 클릭해서 선택하세요

2. 삭제할 블록의 문구

이 문구가 들어 있는 영역을 찾습니다. (예: 새 태그 (태그칸))

3. 삭제할 범위 선택

문구를 담고 있는 바깥 영역들입니다. 지우려는 범위를 고르세요. 보통 제목과 목록을 모두 포함하는 카드 전체를 고르면 됩니다.

도움말

  • 저장된 파일 이름은 원본이름_정리본.html 이며, 브라우저 다운로드 폴더에 저장됩니다.
  • 같은 문구가 여러 번 나오면 아래 목록에 모두 표시됩니다. 필요한 만큼 반복해서 지우면 됩니다.
  • 결과가 마음에 들지 않으면 원본 파일을 다시 올려서 다른 범위를 선택하세요.
