붙여넣는 방법 (글 하나에 1분)
  1. 아래 목록에서 「글 열기」는 확인용이고, 수정은 Blogger 관리 화면에서 해요: blogger.com → 「글」 → 해당 글 제목에 마우스 → 연필(수정).
  2. 편집기 왼쪽 위의 연필 아이콘을 눌러 「HTML 보기」로 바꿔요. (글쓰기 보기에 붙이면 계산기가 깨져요.)
  3. HTML 창 안을 클릭 → Ctrl+A 전체 선택 → Delete → 여기서 「HTML 복사」 누른 뒤 Ctrl+V.
  4. 오른쪽 「글 설정」 → 「검색 설명」을 열고, 여기서 「검색 설명 복사」 한 내용을 붙여넣어요.
  5. 오른쪽 위 「업데이트」. 글 주소(퍼머링크)는 건드리지 마세요. 끝나면 여기서 체크 ✓.
사진은 그대로 두면 돼요. 새 HTML에 원래 사진 주소가 들어 있고, 비어 있던 사진 설명(alt)만 채웠어요. 업데이트 후 글을 한 번 열어 계산기 버튼이 눌리는지 확인하세요.
