붙여넣는 방법 (글 하나에 1분)
  1. 아래 목록에서 제목을 누르면 복사돼요. Blogger 글 검색창에 붙여넣고 Enter → 나온 글을 눌러 편집기를 열어요.
  2. 편집기가 코드 화면(HTML 보기)이면 그대로 돼요. 글자가 알록달록한 코드로 보이면 맞아요. 아니면 왼쪽 위 연필 아이콘 → 「HTML 보기」.
  3. 코드 화면을 클릭 → Ctrl+A → Delete → 여기서 「HTML 복사」 → Ctrl+V 까지 하고, 업데이트 전에 오른쪽 「글 설정」으로 가요.
  4. 오른쪽 「검색 설명」을 열고 → 안의 글을 전부 지우고 → 여기서 「검색 설명 복사」 → 붙여넣기.
  5. 오른쪽 위 「업데이트」. 끝나면 여기서 체크.
