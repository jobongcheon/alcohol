# Smart Life Calc · くらしの計算ツール — 애드센스 재심사용 수정본

두 블로그(영어 smartlifecalc.com 32글, 일본어 daily-glow-up.blogspot.com 22글)의 글을 Blogger 백업(feed.atom)에서 꺼내 분석하고 고친 결과예요.

## 왜 거절됐나 (데이터)
- 사이트 나이: 영어 4주, 일본어 3주. 그 사이 두 번 신청.
- 54개 글 전부 같은 틀. 글 안에 FAQ가 2~3번, 같은 표가 2번 반복(이전 "수정"이 기존 글 뒤에 덧붙이는 방식이었기 때문).
- 외부 출처 링크 0개(About 페이지는 CFPB·CDC 자료를 썼다고 적혀 있음). 이미지 alt 전부 비어 있음.
- 주제가 전부 구글이 직접 답을 띄우는 포화 주제(모기지·BMI·나이·날짜).

## 무엇을 고쳤나 (글마다)
1. 짧은 블록 + 긴 가이드를 하나의 글로 합침. FAQ 1개, 표 1개, 예시 1개.
2. 글마다 고유 섹션 2개 추가(사례·비교표·법률/지역 차이·체크리스트 등, 글마다 형식 다름).
3. 출처 2~3개(미국: CFPB·IRS·BLS·DOL·CDC 등 / 일본: 国税庁·厚労省·e-Gov 등) 링크.
4. 이미지 alt, 검색 설명(meta), FAQ 제목·글 제목 문구를 글마다 다르게.
5. 하단 공통 상자 → 그 글과 관련된 계산기 3개로.
6. 개인정보 페이지에서 실제로 없는 Amazon 제휴 문단 삭제.

## 파일
- `index.html` + `posts.json`: 복사용 페이지(아티팩트로도 발행). 글마다 「HTML 복사」→ Blogger HTML 보기에 붙여넣기.
- `en/*.html`, `jp/*.html`: 글별 새 HTML(Blogger HTML 보기에 그대로 붙여넣는 본문).
- `tools/`: 분석(audit.py)·합치기(merge.py)·페이지 생성(build_page.py)·작가 지시서(BRIEF.md).

## 붙여넣은 뒤 할 일
- 일본어 블로그 휴지통의 about 페이지 영구 삭제.
- Search Console 등록 → 사이트맵 제출 → 글 색인 요청. `site:smartlifecalc.com` 결과 수 확인.
- 재신청은 12월 말 이후, 두 블로그 2주 이상 간격.
